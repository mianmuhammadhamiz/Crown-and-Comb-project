# Crown-and-Comb-project
A stylish salon website for Crown and Comb Parlor Salon, showcasing its royal-inspired brand identity, beauty services, and elegant salon experience using HTML and CSS.
## Project Description
Crown and Comb Parlor Salon is a modern and elegant salon website designed to showcase beauty and hair-care services. It represents a royal-inspired brand identity through its luxurious branding and attractive design.
**Slogan:** Where Beauty Meets Royalty — Every Strand Deserves a Crown.
